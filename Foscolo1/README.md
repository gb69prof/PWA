# L'eco di Foscolo – PWA

PWA statica pronta da aprire o pubblicare.

## Come usarla

### Apertura veloce
- estrai lo zip
- apri la cartella
- avvia un server locale semplice

Esempio con Python:

```bash
python -m http.server 8000
```

Poi apri nel browser:

```text
http://localhost:8000
```

### Pubblicazione
Puoi caricare l'intera cartella su GitHub Pages, Netlify o altro hosting statico.

## Cosa include
- copertina
- 10 capitoli su Foscolo
- doppia pagina su desktop
- pagina singola su mobile
- testo selezionabile
- note salvate in locale
- manifest e service worker di base
