# Dentro la sera – esperienza immersiva

Versione statica, senza React, senza Vite, senza build.

## Come usarla su GitHub Pages

1. Crea un repository GitHub.
2. Carica direttamente `index.html` nella radice del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, scegli:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ root**
5. Salva.

Dopo qualche minuto, la pagina sarà visibile su GitHub Pages.

Questa versione è pensata proprio per evitare la pagina bianca dovuta a build React/Vite non eseguita o configurazione `base` errata.
