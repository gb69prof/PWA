LA LOCANDIERA - PWA DIDATTICA

Come testare in locale:
1. Apri un terminale nella cartella del progetto.
2. Esegui: python3 -m http.server 8000
3. Apri nel browser: http://localhost:8000
4. Verifica installazione PWA da Chrome/Edge e da Safari su iPad/iPhone con "Aggiungi a Home".

Come pubblicare su GitHub Pages:
1. Carica tutti i file del progetto in un repository.
2. Attiva GitHub Pages dalla branch principale o dalla branch desiderata.
3. Usa come URL finale qualcosa del tipo:
   https://TUO-UTENTE.github.io/NOME-REPOSITORY/
4. Apri l'URL dal telefono o tablet e verifica:
   - presenza del prompt di installazione o voce "Aggiungi a Home"
   - avvio standalone
   - navigazione tra le pagine
   - funzionamento offline della shell UI dopo una prima visita online
